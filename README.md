# bu_studymaterials

Study materials for university coursework, organized by course, part, and topic.

## Content Guidelines

These rules apply to every note in this repository:

1. **Plain language.** Concepts are explained simply, in layman's terms. A single read-through should be enough to understand the material — no rereading required.
2. **Authenticity.** Every concept, claim, and quotation is drawn from genuine, identifiable sources. Quotations are verbatim where applicable, with the source and location (e.g. chapter) cited.
3. **Zero fabrication.** No invented facts, sources, examples-passed-off-as-primary-text, or fake data. If something can't be verified, it is left out.
4. **One topic at a time.** Material is produced and committed topic by topic, not in one large batch, to keep each session focused.

## Structure

    <course-name>/<part-name>/<topic-name>/notes.md
